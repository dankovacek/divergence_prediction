Introduction#

Note

Before proceeding with the computations in the notebook, the streamflow time series and (optionally) catchment boundaries from the HYSETS dataset must be downloaded from the HYSETS open data repository. Some data are provided in the data/ folder as part of this repository. Data pre-processing can be skipped by downloading the input data files from (add dataset repository link). Note The station timeseries file has been updated, the current filename is HYSETS_2023_update_QC_stations.nc

The data used in this study comes from The Hydrometeorological Sandbox École de Technologie Supérieure (HYSETS) []. The HYSETS data, including streamflow time series and attributes for 14,425 catchments can be accessed at https://osf.io/rpc3w/. We use a subset of approximately 1620 catchments contained in major basins covering and bounding British Columbia, as shown in Figure 1. Ten climate indices were processed from Daymet for this subset, for details see BCUB - A large sample ungauged basin attribute dataset for British Columbia, Canada [] (https://doi.org/10.5194/essd-2023-508).

For this experiment we use the following files:

  • Daily average streamflow time series: streamflow timeseries are now in a single netcdf file. These should be downloaded from the open data repository linked above and saved under data/HYSETS_2023_update_QC_stations.nc

  • Catchment attributes: filename: BCUB_watershed_attributes_updated.csv. This file is provided in the data/ folder, and it was modified from the original file HYSETS_watershed_properties.txt in the HYSETS dataset with ten added climate indices as described in [].

Data pre-processing overview#

Note that these steps are optional and the end results of these pre-processing steps are provided in the open data repository.

get updated data sources and validate catchment attributes#

  1. Extract catchment attributes using updated catchment geometries where available (optional, updated catchment geometries are saved in data/Catchment_polygons.geojson),

  2. Process climate indices for HYSETS catchments in the study region (optional, pre-processed attributes can be found in the data folder: BCUB_watershed_attributes_updated_20260129.csv)

Pre-process streamflow data based on key assumptions#

  1. Define sensitivity test parameters:

    • Bitrate: the number of quantization levels to encode the streamflow time series \(N_s = 2^b\). This is done to test the sensitivity of the predictive model to information loss.

    • Prior: when computing the Kullback-Leibler divergence (\(D_{KL} (P||Q) = P \text{log}\frac{P}{Q}\)), the simulated distribution Q can’t contain zero probabilities, in other words we must prevent the model from saying observed states are impossible. This is achieved by applying a prior distribution to q (the simulated series) in order to avoid division by zero. The KL divergence is then computed on the posterior \(Q'\).

    • Minimum record length: we set the minimum record length to 1 year in order to see the sensitivity of the model to record length,

    • Record “completeness”: a (hydrological) year must satisfy a minimum completeness threshold in terms of allowable missing days in any month. This threshold is set to avoid seasonal bias, but it is at the expense of information discard.

Compute Kullback-Leibler divergence measures for catchment pairs#

The quantization step then computes counts based on the proportion of the error interval covered by each bin. This has a smoothing effect on the discrete PMF, with an increasing effect as the bitrate (number of bins / quantization levels) increases and bin intervals shrink.

  1. Compute the (Shannon) entropy of the streamflow time series for each bitrate and prior.

  2. Compute the KL divergence (KLD), Earth Mover’s Distance (EMD), and total variation distance (TVD) for each pair of stations meeting the minimum record / minimum concurrency criteria.

def retrieve_timeseries_discharge(stn, min_flow=1e-4):
    watershed_id = ws_id_dict[stn]
    df = ds['discharge'].sel(watershed=str(watershed_id)).to_dataframe(name='discharge').reset_index()
    df = df.set_index('time')[['discharge']]
    # regardless of whether the INPUT data is clipped to 
    # match the LSTM input data, the target data should be clipped
    # such that the target distribution is held constant
    df.dropna(inplace=True)
    # clip minimum flow to 1e-4
    df['discharge'] = np.clip(df['discharge'], min_flow, None)
    df.rename(columns={'discharge': stn}, inplace=True)
    df[f'{stn}_uar'] = 1000 * df[stn] / da_dict[stn]
    return df

def retrieve_nonconcurrent_data(s1, s2):
    df1 = retrieve_timeseries_discharge(s1)
    df2 = retrieve_timeseries_discharge(s2)
    return pd.concat([df1, df2], axis=1, join='outer')

Record-length and completeness filtering#

from time import time

length_thresholds = [2, 5, 10, 15, 20, 40]
completeness_thresholds = [0.1, 0.5, 0.9, 0.96] # 96% allows 1 missing day per month

inputs = []
with Pool(processes=16) as pool:  
    input_data = pool.map(retrieve_timeseries_discharge, bcub_stations)

def compute_completeness(df, thresh, comp):
    stn = df.columns[0]
    s = df[stn]
    unique_years = s.index.year.nunique()
    if unique_years < thresh:
        return (stn, thresh, comp, False)

    # monthly counts at native timestamps (non-null observations)
    m = s.groupby(s.index.to_period("M")).count()  # index is PeriodIndex (M)
    # days in each month (vectorized)
    denom = pd.Series(m.index.days_in_month, index=m.index)

    pct = (m / denom)

    # year is period.year
    complete_month = (pct >= comp)

    # a year is "complete" if all 12 months pass
    complete_year = complete_month.groupby(m.index.year).all()

    sufficient_length = int(complete_year.sum()) >= thresh
    unique_years = s.index.year.unique()
    year_str = ','.join([str(y) for y in unique_years])
    return (stn, thresh, comp, sufficient_length, year_str)

def compute_empirical_cdf(values):
    """Compute the empirical CDF of a given set of values."""
    sorted_values = np.sort(values)
    cdf = np.arange(1, len(sorted_values) + 1) / len(sorted_values)
    return sorted_values, cdf

def plot_cdf(value_sets, labels):
    """Plot the empirical CDF of a given set of values."""
    fig = figure(title="", width=700, height=350)
    lines = ['solid', 'dashed', 'dotted']
    for values, label, d in zip(value_sets, labels, lines):
        axis_label = ' '.join(label.split('_'))
        if c.startswith('land_use'):
            label = c.split('_')[-1] + ' ' + label.split('_')[-1]
        sorted_values, cdf = compute_empirical_cdf(values)
        fig.line(sorted_values, cdf, line_width=2, color='navy', 
                 line_dash=d, legend_label=f'{label}')
        fig.xaxis.axis_label = label
        fig.yaxis.axis_label = 'Cumulative Probability'
    fig.legend.location = 'bottom_right'
    fig.legend.background_fill_alpha = 0.5
    return fig
