Predict KL Divergence from Catchment Attributes#

Introduction#

We compute the ordinary and linear moment statistics of runoff time series for a large sample of catchments. We then test the predictability of these statistics from catchment attributes using a gradient boosting machine learning approach. The purpose of testing predictability of the order statistics and L-moments is to fully describe parametric distributions for estimating streamflow distributions (flow duration curves), a common problem in applied hydrology.

Catchment attributes are used as predictors of each order statistic. Attributes are added cumulatively in successive tests to compare the contribution of catchment attribute groups related to climate, terrain, land cover, and soil.

Here we test the predictability of KL divergence between the unit area runoff PMFs between a very large sample (\(\sim 4 \times 10^5\)) of catchment pairs. The PMFs were computed by Kernel Density Estimation (KDE) that incorporates an adaptive bandwidth to reflect an assumed model of measurement uncertainty.

Using the XGBoost python library, we use gradient boosting to test the predictability of KL divergence from catchment attributes of both catchments in the pairing.

Run XGBoost Regression#

The same problem setup applies for the regression prediction problem which is to optimize the discriminant function and the input signal quantization simultaneously to minimize the error in predicting the KL divergence from catchment attributes.

Instead of predicting a scalar measure which is a feature of a single location, the key difference in this step is the target variable describes a measure of the difference in runoff between pairs of locations. This approach asks whether the Kullback-Leibler Divergence (KLD) of the distribution of unit area runoff between two locations can be predicted from the attributes of both catchments (and their differences) using the gradient boosted decision tree method, which is also capable of predicting continuous variables, in this case \(D_\text{KL}\).

Train-test split#

The input dataset is pairwise comparisons of just over 1300 (streamflow) monitored catchments, their attributes, and the attribute differences. After filtering for data concurrency (minimum 1 year, < 5 days missing per month) and maximum distance between basin centroids (500 km) we are left with roughly 225K pairs. The pairwise setup means that station data appears in more than one row. As a result, the attributes of stations can end up in both training and test sets if we simply split by randomly assigning rows to training or test sets. We can’t simply cut edges until the graph is separated because it is a generalization of the “keeping a subset of vertices” problem in graph theory which is NP-hard.

To address this issue we split the dataset spatially to create partitioned datasets for each fold and draw samples from within the “cluster” while filtering all edges between the fold and the rest of the set. The end goal is to generate training folds where the official_id does not appear in both training and test set, in either donor or target column. One problem remains, and that is to generate training and test sets with some assurance that the target variable distributions match to some degree, but this is less critical than ensuring there is no data leakage between training and test data.

Next we create training/test splits and visualize how the target variable distributions compare.

def add_attributes(attr_df, df, attribute_cols):
    """
    Adds attributes from the df_attributes to the df_relations based on the 'donor' and 'target' columns
    using map for efficient lookups.

    Parameters:
    df_attributes (pd.DataFrame): DataFrame with 'id' and attribute columns.
    df_relations (pd.DataFrame): DataFrame with 'donor' and 'target' columns.
    attribute_cols (list of str): List of attribute columns to add to df_relations.

    Returns:
    pd.DataFrame: Updated df_relations with added attribute columns.
    """
    attribute_cols = [c for c in attribute_cols if c != 'centroid_distance_km']
    # Create dictionaries for each attribute for quick lookup
    attr_dicts = {col: attr_df.set_index('official_id')[col].to_dict() for col in attribute_cols}

    
    # Add target attributes
    feature_cols = []
    for col in attribute_cols:
        df[f'target_{col}'] = df['donor'].map(attr_dicts[col])
        feature_cols.append(f'target_{col}')

    # Add donor attributes
    for col in attribute_cols:
        df[f'donor_{col}'] = df['donor'].map(attr_dicts[col])
        feature_cols.append(f'donor_{col}')
    for col in attribute_cols:
        df[f'{col}_diff'] = df[f'target_{col}'] - df[f'donor_{col}']
        feature_cols.append(f'{col}_diff')

    return df, feature_cols

def compute_ecdf(data):
    """Compute the empirical cumulative distribution function (ECDF) for a 1D array of data."""
    # Sort the data
    sorted_data = np.sort(data)
    # Compute the ECDF values
    ecdf_values = np.arange(1, len(sorted_data) + 1) / len(sorted_data)
    return sorted_data, ecdf_values

from typing import List, Tuple, Union

def summarize_feature_importance(
    dfs: Union[pd.DataFrame, List[pd.DataFrame]],
    importance_col: str = "importance_total_gain",
) -> Tuple[pd.DataFrame, pd.DataFrame]:
    """
    Summarize XGBoost feature importance stability across trials.

    Inputs:
      - dfs: a single DataFrame or list of DataFrames with columns:
             ['feature', importance_col, 'trial'] and optionally 'fold'
      - importance_col: column with importance values (e.g., 'importance_total_gain')

    Returns:
      - summary_df: per-feature table with mean share, IQR, presence, rank stats
      - per_trial_df: per (trial, feature) table with normalized 'share' and 'rank'
    """
    df = pd.concat(dfs, ignore_index=True) if isinstance(dfs, list) else dfs.copy()
    needed = {"feature", importance_col, "trial"}
    missing = needed - set(df.columns)
    if missing:
        raise ValueError(f"Missing required columns: {missing}")

    # 1) Collapse folds within each trial (mean)
    per_trial = (df.groupby(["trial", "feature"], as_index=False)
                   .agg({importance_col: "mean"}))

    # 2) Normalize per trial to sum-to-1 shares
    per_trial["share"] = per_trial.groupby("trial")[importance_col] \
                                  .transform(lambda x: x / max(x.sum(), 1e-12))

    # 3) Rank within trial: 1 = most important
    per_trial["rank"] = per_trial.groupby("trial")["share"] \
                                 .rank(ascending=False, method="average")

    # 4) Aggregate across trials: strength + stability
    def iqr(x): 
        q = np.percentile(x, [25, 75])
        return float(q[1] - q[0])

    summary = (per_trial.groupby("feature")
               .agg(mean_share=("share", "mean"),
                    iqr_share=("share", iqr),
                    presence_rate=("share", lambda s: float((s > 0).mean())),
                    mean_rank=("rank", "mean"),
                    iqr_rank=("rank", iqr),
                    n_trials=("trial", "nunique"))
               .sort_values(["mean_share", "presence_rate"], ascending=[False, False])
               .reset_index())

    return summary, per_trial

def _finite_sample_quantile(scores: np.ndarray, alpha: float) -> float:
    """
    Conformal finite-sample choice: k = ceil((n+1)*(1-alpha)), return k-th order statistic.
    """
    scores = np.asarray(scores, dtype=float)
    n = scores.size
    k = int(np.ceil((n + 1) * (1 - alpha)))
    k = min(max(k, 1), n)  # clamp to [1, n]
    # k-th order statistic (1-indexed) -> index k-1 (0-indexed)
    return float(np.partition(scores, k - 1)[k - 1])

def fit_conformal_from_oof(df: pd.DataFrame, alpha: float = 0.10) -> dict:
    """
    Given OOF quantile predictions (y_lower, y_upper) and actual, compute CQR offsets.
    """
    # One-sided conformity scores (only violations count)
    sL = np.maximum(df['y_lower'].to_numpy() - df['actual'].to_numpy(), 0.0)
    sU = np.maximum(df['actual'].to_numpy() - df['y_upper'].to_numpy(), 0.0)
    qL = _finite_sample_quantile(sL, alpha)
    qU = _finite_sample_quantile(sU, alpha)
    return {"qL": qL, "qU": qU, "alpha": alpha}

def apply_conformal(preds: pd.DataFrame, calibrator: dict) -> pd.DataFrame:
    """
    Apply learned offsets to predicted quantiles. Expects y_lower, y_upper columns.
    """
    out = preds.copy()
    out['y_lo_cal'] = out['y_lower'] - calibrator['qL']
    out['y_hi_cal'] = out['y_upper'] + calibrator['qU']
    # optional safety: enforce order
    out['y_lo_cal'] = np.minimum(out['y_lo_cal'], out['y_hi_cal'])
    return out

def interval_coverage(df, lo, hi, y='actual'):
    in_int = (df[y] >= df[lo]) & (df[y] <= df[hi])   # closed interval
    n = len(df)
    k = int(in_int.sum())
    p = k / n
    print(f'Interval coverage: {p:.2%} (n={n}, covered={k})')

def compute_empirical_cdf(data):
    sorted_data = np.sort(data)
    cdf = np.arange(1, len(sorted_data) + 1) / len(sorted_data)
    return sorted_data, cdf

def cqr_calibrate_two_sided(df: pd.DataFrame, alpha: float = 0.10):
    df = df.copy()
    sL = np.maximum(df['y_lower'] - df['actual'], 0.0).to_numpy()
    sU = np.maximum(df['actual'] - df['y_upper'], 0.0).to_numpy()
    nL, nU = len(sL), len(sU)
    # use (1 - alpha/2) quantile per side (finite-sample indexing)
    kL = int(np.ceil((nL + 1) * (1 - alpha/2))); kL = min(max(kL,1), nL)
    kU = int(np.ceil((nU + 1) * (1 - alpha/2))); kU = min(max(kU,1), nU)
    qL = float(np.partition(sL, kL - 1)[kL - 1])
    qU = float(np.partition(sU, kU - 1)[kU - 1])
    df['y_lo_cal'] = df['y_lower'] - qL
    df['y_hi_cal'] = df['y_upper'] + qU
    return df, (qL, qU)

def create_contour_plot(dfv, log_transform_target=True):
    sfig = figure(title=f'', toolbar_location='above')#, x_axis_type='log', y_axis_type='log')
    # ------------------------------------------------
    # 1. Get data for KDE (same columns as your scatter)
    # ------------------------------------------------
    X = dfv[['actual', 'y_med']].to_numpy(float)

    if not log_transform_target:
        X = np.exp(X)

    # Optionally subsample if needed for speed
    # idx = np.random.choice(len(X), size=100_000, replace=False)
    # X = X[idx]

    # ------------------------------------------------
    # 2. 2D KDE using FFTKDE
    # ------------------------------------------------
    n_grid = 128  # tweak for resolution vs speed

    kde = FFTKDE()
    grid, Z = kde.fit(X).evaluate(grid_points=(n_grid, n_grid))
    # grid: (n_grid**2, 2), Z: (n_grid**2,)

    Z = Z.reshape(n_grid, n_grid)

    # Build x/y coordinate vectors for the grid
    x_vals = np.linspace(grid[:, 0].min(), grid[:, 0].max(), n_grid)
    y_vals = np.linspace(grid[:, 1].min(), grid[:, 1].max(), n_grid)

    # ------------------------------------------------
    # 3. Extract contours as polylines (no plotting)
    # ------------------------------------------------
    # Choose levels by quantiles of density, or fixed values
    level_vals = [0.6, 0.8, 0.9, 0.95, 0.99]
    levels = np.quantile(Z, level_vals)

    xs_list, ys_list, level_texts = [], [], []
    label_x, label_y, label_level = [], [], []

    Z_total = Z.sum()

    for level in levels:
        # cumulative exceedance mass: P(Z >= level)
        mask = Z >= level
        p_exceed = Z[mask].sum() / Z_total   # in [0, 1]

        contours = measure.find_contours(Z, level)

        for c in contours:
            rows = c[:, 0]
            cols = c[:, 1]

            xs = np.interp(cols, np.arange(n_grid), x_vals)
            ys = np.interp(rows, np.arange(n_grid), y_vals)

            if len(xs) < 2:
                continue

            xs_list.append(xs)
            ys_list.append(ys)

            # label in terms of exceedance frequency, e.g. 0.85 or 85%
            label_str = f"{p_exceed:.2f}"      # or f"{int(p_exceed*100)}%"

            level_texts.append(label_str)

            mid = len(xs) // 2
            label_x.append(xs[mid])
            label_y.append(ys[mid])
            label_level.append(label_str)

    # ------------------------------------------------
    # 4. Feed contour lines + labels into Bokeh
    # ------------------------------------------------
    contour_source = ColumnDataSource(data=dict(
        xs=xs_list,
        ys=ys_list,
        level=level_texts,
    ))

    label_source = ColumnDataSource(data=dict(
        x=label_x,
        y=label_y,
        text=label_level,
    ))
    
    # Draw contours on your existing figure `sfig`
    sfig.multi_line(
        xs="xs",
        ys="ys",
        source=contour_source,
        line_width=1,
        line_alpha=0.8,
    )

    labels = LabelSet(
        x="x",
        y="y",
        text="text",
        source=label_source,
        text_font_size="8pt",
        text_alpha=0.8,
    )
    sfig.line([-6, 6], [-6, 6], line_color='black', line_width=1, line_dash='dotted')
    sfig.add_layout(labels)
    sfig.xaxis.axis_label = r'Actual $$ \log D_{KL}$$ [bits/sample]' if log_transform_target else r'Actual $$ \log D_{KL}$$ [bits/sample]'
    sfig.yaxis.axis_label = r'Predicted $$\log D_{KL}$$ [bits/sample]' if log_transform_target else r'Predicted $$\log D_{KL}$$ [bits/sample]'
    # sfig.legend.background_fill_alpha = 0.6
    # sfig.legend.location = 'top_left'
    # sfig.legend.click_policy = 'hide'
    return sfig
